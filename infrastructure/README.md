# Infraestrutura

Arquivos declarativos da VM e do proxy.

- systemd/: serviços do RC Geradores.
- nginx/: configuração Nginx para o modo que usa Nginx local.
- env/: exemplo versionado das variáveis de ambiente.
- docs/: operação do proxy externo/NPM.

Os entrypoints operacionais permanecem em ops/ para compatibilidade de deploy e manutenção da VM.
