# Área de laboratório

Coloque cada nova controladora em `lab/<fabricante>/<modelo>/modbus/`. Preserve o
nome original do arquivo e registre no diretório `homologation` de onde ele veio,
firmware conhecido e checksum SHA-256.

O estado LAB nunca autoriza comandos nem promoção automática. Um mapa documental
não é evidência de funcionamento em campo.
