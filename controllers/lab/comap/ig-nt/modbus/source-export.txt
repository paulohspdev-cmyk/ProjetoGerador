  Bits 16-31: Time (number of minutes from midnight => 0-1439)

  Bits 32-44: Duration (in minutes => 1-1439) (N/A in OFF mode)
  Bits 45-47: Mode
    0 = OFF
    1 = Once
    2 = Daily
    3 = Weekly
    4 = Monthly
    5 = Monthly (in day of week)
    6 = Period
    7 = N/A (OFF)

  Bits 48-63: N/A

In Daily Mode:
  Bits 48-57: Repeat period (in days => 1-1023)
  Bits 58-59: Weekend mode:
    0 = including weekend days
    1 = except weekend days
    2 = postpone weekend days (to Monday)
    3 = N/A
  Bits 60-63: N/A

  Bits 48-53: Repeat period (in weeks => 1-63)

  Bit     55: on Tuesday

  Bit     57: on Thursday
  Bit     58: on Friday
  Bit     59: on Saturday
  Bit     60: on Sunday

          Bit 47     => Confirmed (1=confirmed)
          Bit 46     => Active (1=active)

          Bits 47-46:  00 => not inverted(white) with asterisk
          Bits 47-46:  01 => inverted(red) with asterisk
          Bits 47-46:  10 => N/A (reserved)
          Bits 47-46:  11 => inverted(orange) without asterisk

          Bits 45-35 => Base

          Bits 34-32 => ECU diagnostic code type
                  =0 =>  DM1
                  =1 =>  KWP2000
                  =2 =>  J1587
                  =3 =>  Cummins
                  =7 =>  COMAP (no ECU diagnostic code)

          Bits 30-24 => Number of occurrences (Always 0 for COMAP)
          Bits 23-19 => Prefix for COMAP / FMI for ECU
          Bits 18- 0 => Fault code for ECU / State index for COMAP

          Name = Prefix Base                (COMAP events)  or
          Name = ECU-Prefix ECU-Diag-Base   (ECU events)
