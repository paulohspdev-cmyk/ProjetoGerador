# InteliLite 4 integration reference — LAB

A ComAp confirma a família InteliLite 4 e suas capacidades de comunicação/InteliConfig. A Victron publica uma tabela de holding registers para integração com InteliLite 4, mas também registra que não conseguiu garantir um mapping universal para todas as configurações ComAp e que os registradores podem precisar ser ajustados.

Por isso este pack é `documented`/LAB, estritamente read-only e não provisionável automaticamente. O coil de start/stop citado pela integração externa não é incluído.
