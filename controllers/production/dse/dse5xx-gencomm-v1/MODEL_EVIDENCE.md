# DSE550 / DSE555 serial GenComm evidence

This pack covers only explicitly identified RS232/RS485 variants. The DSE GenComm v1.29 protocol names DSE550, DSE555, DSE5210 and DSE5220. DSE obsolescence documentation separately lists No-Comms and communication-equipped variants, so generic model names are intentionally not provisioned automatically.

All commands remain disabled.
