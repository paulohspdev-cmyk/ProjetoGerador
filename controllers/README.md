# Controladoras

Domínio autoritativo de suporte a controladoras.

- production/: Controller Packs promovidos para produção.
- lab/: packs em investigação/homologação.
- schema/: schemas dos manifests.
- catalog/: catálogo de modelos.
- tools/: probes/importadores/bootstrap específicos de controladoras.
- homologation/: matriz, evidências e ferramentas de homologação de comandos.

Regra: documentação não promove comando. Escrita industrial só é liberada por pack field_validated, firmware exato homologado, capability e contrato de comando.
