# Frontend

Tudo que o operador vê e usa fica neste domínio.

- src/features/: funcionalidades de negócio (generators, scada, auth).
- src/design-system/ui/: primitives reutilizáveis, botões, cards, dialogs, inputs e tabelas.
- src/layout/: sidebar, topbar, shell e providers de layout/tema.
- src/theme/: cores, tipografia, espaçamento, sombras e estilos globais industriais.
- src/assets/: SVGs e assets importados pelo bundle.
- public/: imagens e arquivos estáticos servidos diretamente.

Regra: código de backend, Rapid ou mapa de controladora não deve entrar aqui.
